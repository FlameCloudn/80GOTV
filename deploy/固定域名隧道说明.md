# 固定域名隧道

双击项目根目录的 `启动固定域名隧道.cmd`。

第一次启动需要：

1. 在自动打开的浏览器中登录 Cloudflare。
2. 输入隧道名称，直接回车会使用 `80gotv`。
3. 输入已经接入该 Cloudflare 账号的固定域名，例如 `cs.example.com`。

设置完成后，脚本会自动启动 80GOTV、绑定域名并连接隧道。以后再次双击时不会重复设置。

保持命令窗口开启，网站才会在线。按 `Ctrl+C` 关闭网站和隧道。

本机设置保存在 `deploy/cloudflare-tunnel.local.ps1` 和 `deploy/cloudflare-config.yml`，这两个文件不会提交到 Git。
