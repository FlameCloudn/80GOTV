# 项目决策记录

记录项目中的关键决策和原因，以后不会忘记"当时为什么这么选"。

---

## 2026-05 | 为什么用 SQLite

决策: 使用 SQLite 作为本地数据库

原因:
- 零配置，不需要装 MySQL 或 PostgreSQL
- 数据库就是一个文件（cs_site.db），备份和迁移只要复制文件
- 单机部署足够用（同时在线人数不超过几百人）
- Flask 内置支持，Python 标准库自带 sqlite3 模块

---

## 2026-05 | 为什么选 Flask

决策: 使用 Flask 框架

原因:
- 轻量，学习曲线低，适合个人项目
- Jinja2 模板引擎直接渲染 HTML，前后端不分离，开发快
- 中文社区活跃，遇到问题容易搜到答案
- 插件丰富（Flask-Login、Flask-WTF 等）

---

## 2026-06 | 为什么迁移到 Turso

决策: 本地 SQLite 改为同时支持 Turso 云数据库

原因:
- 项目需要多人协作时，本地 SQLite 不方便共享数据
- Turso 是基于 libsql 的边缘数据库，兼容 SQLite 语法，迁移成本低
- 环境变量控制：有 TURSO_URL 就用云端，没有就用本地 SQLite，两种模式共存
- 免费额度足够个人项目使用
