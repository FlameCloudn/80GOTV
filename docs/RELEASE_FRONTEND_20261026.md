## 接入修复

- 首页保留新版队标、选手头像和排版，同时保留缺失评分与真实 0 的区别、真实评论数和固定排序。
- 保留已修复的登录、权限、提交保护、错误返回格式、请求大小限制和数据库连接关闭。
- 保留比赛结果、BP 操作和预测重算的校验，接入新版完整 BP 日志展示。
- 修复新版战报遇到缺失评分时出错、选手页新标题与旧数据保护规则不匹配的问题。
- 新版选手对比、表现条、队伍选手卡和近期比赛，不得把未知数据当作实测 0，不得给未知队伍归属或平局强行判断胜负。
- 手机比赛筛选的赛事标签不再被下拉框挤成两行，保留新版颜色和布局。

- 不更改评分公式，不重新计算或覆盖真实历史数据。新增展示使用现有统计规则。

## 保留边界

实际页面复核确认：主比赛页及详细页按回合数计算平均值，战报 MVP 的部分指标按地图计算平均值，因此同一场的 ADR、KAST 可能略有不同。与 `3bf59dc` 逐项对照后确认这是既有差异，不是此次合并造成。本轮不额外改动这两种计算方式，也不把“页面已正常打开”说成所有统计方式已完全统一。

真实 Steam 登录、邮件投递、真实对局持续接入不在本次前端发布中重新验证。正式网站不插入测试账号或比赛。
