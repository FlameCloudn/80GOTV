# Country Flag Emoji Font

`TwemojiCountryFlags.woff2` is vendored unchanged from
`country-flag-emoji-polyfill@0.1.8`:
https://github.com/talkjs/country-flag-emoji-polyfill

The font is a flag-only subset of Mozilla's Twemoji font. The artwork is
by the Twemoji contributors and is licensed under CC BY 4.0. See the
included `LICENSE.md` for attribution and license links.

Only flag emoji use this font; the website does not change the user's
installed fonts or load a third-party script.
