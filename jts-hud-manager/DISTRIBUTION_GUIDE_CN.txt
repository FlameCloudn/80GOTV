80GOTV 导播软件使用说明

使用方式：把安装程序交给实际负责导播的人。比赛数据只由那台导播电脑上传和同步；制作安装包的电脑不需要开机，也不参与比赛。

一、第一次打开
1. 双击安装程序，安装后打开“JTs Hud Manager 中文版”。
2. 打开左下角“设置”。
3. 网站地址填写 https://80gotv.cn。
4. 选择网站上的比赛，点击“同步比赛资料”。
5. 返回“导播台”，点击“检查完整连接”。四个状态都正常后再开赛。

二、放进 OBS
1. 在“导播台”找到“OBS 浏览器源”，点击“复制”。
2. OBS 中添加“浏览器”来源，粘贴刚才的地址。
3. 宽度填 1920，高度填 1080。
4. 浏览器源放在游戏捕获上方。游戏画面仍由 OBS 的游戏捕获负责。
5. 需要音乐时，在浏览器源属性中启用“使用 OBS 控制音频”；若当前 OBS 没有该选项，再添加“应用程序音频捕获”，选择本导播软件。

三、每场比赛开始前
1. 导播电脑上的观战账号必须在第一回合开始前进入服务器。
2. 导播软件保持打开，确认“CS2 数据”为“正在接收”。
3. 再点一次“检查完整连接”。
4. 如果中途才进入服务器，之前回合的胜利原因无法补回来，只会从连接后的回合开始记录。

四、比赛中怎么按
1. BP 锁定后，导播决定何时点“展示 BP”。
2. 正常比赛点“自动跟随”。只想保留比赛 HUD 时点“切出覆盖层”。
3. 战术暂停、技术暂停和中场会自动识别；识别失败时可用对应按钮手动展示。
4. 一张图打完点“单图结束”。整个 BO3 打完点“BO3 结束”。
5. 画面异常时立即点“全部隐藏”，OBS 游戏画面不会受到影响。

五、必须注意
1. 比赛不是连续播放流程，BP、中场、赛后等页面由导播按现场情况分步控制。
2. 不要在比赛中途切换网站比赛；需要切换时先重新同步，再检查完整连接。
3. 不要公开转播密钥，也不要把密钥发到群里或放进截图。
4. 替补会作为自由替补导入，不会自动归入某一支队伍。
