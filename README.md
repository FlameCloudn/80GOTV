\# 校园 CS2 赛事网站



一个完整的 CS2 赛事信息管理系统，包含前台展示和后台管理功能。



\## 功能特性



\### 前台功能

\- 📰 新闻资讯：发布和浏览赛事新闻

\- 🎮 比赛信息：查看即将进行和正在进行的比赛

\- 📊 赛果展示：查看已结束比赛的详细数据

\- 🏆 赛事管理：展示各类赛事信息和对阵表

\- 👤 选手资料：查看选手详细信息和历史数据

\- 📈 数据排行：多维度数据排行榜（Rating、K/D、ADR 等）

\- 🌓 主题切换：支持浅色/深色模式，自动跟随系统



\### 后台功能

\- 队伍管理：添加、编辑、删除队伍信息

\- 选手管理：管理选手资料和队伍归属

\- 赛事管理：创建和管理各类赛事

\- 比赛管理：安排比赛、录入比分

\- 数据录入：为已结束的比赛录入详细选手数据

\- 新闻管理：发布和编辑新闻文章



\## 环境要求



\- Python 3.9 或更高版本

\- 现代浏览器（Chrome、Firefox、Edge、Safari）

\- 操作系统：Windows、macOS 或 Linux



\## 安装步骤（从零开始）



\### 第一步：安装 Python



\#### Windows 用户

1\. 访问 \[https://www.python.org/downloads/](https://www.python.org/downloads/)

2\. 下载最新的 Python 3.x 版本（例如 Python 3.11）

3\. 运行安装程序，\*\*务必勾选 "Add Python to PATH"\*\*

4\. 点击 "Install Now" 完成安装

5\. 打开命令提示符（按 Win+R，输入 `cmd`，回车），输入 `python --version` 验证安装



\#### macOS 用户
